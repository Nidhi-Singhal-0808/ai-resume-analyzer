# AI Resume Analyzer & ATS Scorer

A lightweight, web-based mini project built with Python, Streamlit, and Google Gemini API to analyze resumes against job descriptions.

## Setup Instructions
1. Clone the repository.
2. Create and activate a virtual environment (`python -m venv venv` & `venv\Scripts\activate`).
3. Install dependencies: `pip install -r requirements.txt`
4. Create a `.env` file in the root directory and add your Gemini API key:
   `GEMINI_API_KEY=your_api_key_here`
5. Run the application: `streamlit run app.py`
