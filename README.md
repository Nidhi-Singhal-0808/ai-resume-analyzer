# AI Resume Analyzer & ATS Scorer

A lightweight, developer-friendly web application built with Python, Streamlit, and Google Gemini AI to evaluate resumes against custom job descriptions.

## Features
* **Instant PDF Parsing:** Quickly extracts text content from uploaded resumes.
* **ATS Score Estimation:** Computes compatibility percentages against specific job roles.
* **Gap Analysis & Feedback:** Identifies key skill gaps and provides smart recommendations via an interactive dashboard.
